# Simplex Metals – Website

Official website for **Simplex Metals**, Mechanical Spares & Equipment Manufacturers, Bhilai (C.G.).
Vite · React · TypeScript · Tailwind CSS v4 · Motion for React · Lenis · Lucide.

```bash
npm install
npm run dev       # local development
npm run build     # production build → dist/
npm run preview   # serve the build locally
```

## Where to edit content

| What | File |
|---|---|
| Company details, contact, vision/mission/values, navigation, headline figures | `src/data/company.ts` |
| Products, specifications, applications | `src/data/products.ts` |
| Industries served | `src/data/industries.ts` |
| Testing, standards, materials, hardening, infrastructure | `src/data/facilities.ts` |
| Future profile content (history, leadership, milestones…) | `profileBlocks` in `src/data/company.ts` – set `published: true` once approved |

## Images

**All photographs on the site are representative**, freely licensed images from Wikimedia Commons
(`public/assets/industries/` and `public/assets/site/`), downloaded by `node scripts/fetch-photos.cjs`.
They illustrate the industries, product types and processes – they are **not** Simplex Metals' own
works, products or customers, and captions/alt text are written accordingly. CC BY / BY-SA licences
require attribution: the `/credits` page (linked in the footer) lists every photo from
`src/data/credits.json`. Keep that page as long as these photos are used.

**Best upgrade:** replace them with real photographs of Simplex products and the Tedesara works.
Put the new file at the same path (e.g. `public/assets/site/rope-drum.jpg`) or change the path in
`src/data/*.ts`, then remove its entry from `credits.json`.

The original brochure photographs are still in `brochure-source/`; `node scripts/crop-brochure.cjs`
re-crops them into `public/assets/{products,manufacturing,testing,hero}` (currently unused – the
prints are too small for web use). The logo in `public/assets/brand/simplex-logo-white.png` is lifted
from the brochure cover; replace it with the clean original logo file (SVG/PNG) when available.
Background textures are generated by `node scripts/make-textures.cjs`.

## Enquiry form

Without a backend, submitting opens the visitor's email app with the enquiry prefilled (to
hkssimplexmetals@gmail.com). To submit directly, copy `.env.example` to `.env` and set
`VITE_ENQUIRY_ENDPOINT` to a service accepting a JSON POST. Honeypot + minimum-fill-time spam guards included.

## Hosting

`npm run build` also runs `scripts/hosting-routes.mjs`, which reads the routes from `src/App.tsx` and
product slugs from `src/data/products.ts` and writes hosting config so real pages return **200** and
unknown URLs return a genuine **404** (showing the site's own 404 page, marked `noindex`):

| Host | Config | Upload |
|---|---|---|
| Netlify | `dist/_redirects` | deploy `dist/` |
| Vercel | `vercel.json` (project root) + `dist/404.html` | deploy the project |
| Apache / cPanel / Hostinger | `dist/.htaccess` + `dist/404.html` | upload the **contents** of `dist/` to `public_html` (`.htaccess` is a hidden file – make sure it is included) |

Adding a product to `src/data/products.ts` or a route to `App.tsx` is picked up on the next build.
